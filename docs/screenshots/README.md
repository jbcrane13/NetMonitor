## To Capture Additional Screenshots Manually

1. **Make sure NetMonitor app is running**
2. **Press ⌘⇧4, then Space** - cursor becomes a camera
3. **Click the NetMonitor window** - screenshot is saved to desktop
4. **Click a different section** in sidebar (Targets, Devices, Tools, Settings)
5. **Repeat step 2-3** for each section
